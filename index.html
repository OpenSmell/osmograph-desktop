Train a Smell Model

Teach the e-nose to tell one smell from another. Record each substance several times, assign it a label, then train. The model is scored out-of-sample with leave-one-recording-out cross-validation — so the accuracy you see is honest, not inflated by training on the same data it's tested against.
1. Tick ≥2 recordings per smell
2. Set a label for each (default: substance name)
3. Set window & quality filters
4. Click Train → load the model in the Dashboard

About Osmograph

            

              
Osmograph is the desktop front-end for the OpenSmell fleet of metal-oxide (MOX) e-noses —
                a collaboration between software, firmware and the people running real sensor rigs.

Privacy

              
Sessions, calibration and hardware profile are stored only on this device. Anything shared to
                the community (data hub / HF sync / sensor models) is sent only when you explicitly choose to submit it.

            

            

              
Getting help / Windows SmartScreen

              
On Windows you may see a blue “Windows protected your PC” prompt on first run. Because
                the installer is not yet signed, click More info → Run anyway. See the website for full details.
