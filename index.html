Vials

Installable ways of working. A domain Vial carries a protocol, a log, and its limits. A decision Vial carries a closed-set claim with its evidence. Neither is a universal smell ID.

0 domain · 0 decisions · 0 sealed
Installed workspaces. A domain Vial keeps the context the sensor cannot: the protocol, the log, the stop rules, and the refusal. Open one to work; install another from the Aromatory.
Decision packs. A decision Vial is a closed-set claim — “on this array, these two smells are distinguishable” — with the source, replicates, 95% lower bound, permutation p-value, limits, and method. It is sealed only when saved evidence passes the local gate.

Train a Smell Model

Teach the e-nose to tell one smell from another. Record each substance several times, assign it a label, then train. The model is scored out-of-sample with leave-one-recording-out cross-validation — so the accuracy you see is honest, not inflated by training on the same data it's tested against.
1. Tick ≥2 recordings per smell
2. Set a label for each (default: substance name)
3. Set window & quality filters
4. Click Train → load the model in the Dashboard

Smell

          

        

        

          
          1 / 1
          
          
          
        

      

      

        
        

          FINGERPRINT · mean settled response per channel
          one shared scale · signed bars carry polarity
        

      

      

        The fingerprint shows the pattern across channels. The bars show
        how far and which way each channel moved. Both describe this array;
        neither is a chemical identification.
      

      

        

          
What the array sees

          

          
Settled response, baseline-relative. Teal = reducing,
            amber = oxidising. n/a means the channel did not move — not a zero.

        

        

          
Closest confusable

          
Ranking smells by steady-response similarity…

          

            
Mean trace

            
            

          

          

            Evidence & method
            

            

              The verdict is the best of level, shape and together, with a 95% lower
              bound and a label-shuffle p-value whose feature choice is repeated inside
              every shuffle. It is a preview from saved replicates, not a trained model.
